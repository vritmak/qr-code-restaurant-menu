# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

# 🍴 AI-Powered QR Code Restaurant Menu

A modern, mobile-first digital menu application built using **React**, **Vite**, and **Google AI Studio**. This app allows restaurant owners to provide a contactless dining experience where customers can scan a QR code to view a dynamic, AI-enhanced menu.

## ✨ Features
*   **Contactless Experience:** Seamlessly transition from physical QR codes to a digital menu.
*   **AI-Enhanced Descriptions:** Leverages the **Gemini API** via Google AI Studio to generate appetizing dish descriptions and categorize items automatically.
*   **Mobile-Responsive:** Optimized for all screen sizes, ensuring a smooth experience for diners on the go.
*   **Real-time Updates:** Instantly update menu items, prices, and availability without reprinting paper menus.
*   **Dynamic UI:** Built with React for a fast, snappy user interface.

## 🛠️ Tech Stack
*   **Frontend:** React.js, Vite
*   **AI Integration:** Google Gemini SDK (Google AI Studio)
*   **Styling:** CSS3 / Tailwind CSS (if applicable)
